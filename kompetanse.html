01 Webdesign +

Jeg designer og bygger nettsider fullstendig fra bunnen — ingen maler, ingen snarveier. Hvert layout er tenkt ut for å lede besøkende mot én konkret handling: ta kontakt, kjøpe eller bestille.

Designet er alltid mobil-first. Det betyr at siden ser bra ut og fungerer perfekt på telefon, nettbrett og desktop — i den rekkefølgen, fordi det er der kundene dine er.

  • Fullstendig skreddersydd layout for din merkevare og bransje
  • Lighthouse-score 100 på ytelse, tilgjengelighet og SEO
  • CSS-animasjoner og overganger som føles high-end
  • Konsekvent visuelt språk — typografi, farger og spacing

HTML5 CSS3 JavaScript Figma Mobil-first CSS Grid Flexbox Animasjoner
02 SEO +

En pen nettside som ingen finner på Google er bortkastet investering. SEO bygges inn fra starten — ikke limt på etterpå. Koden er semantisk, strukturen er logisk, og innholdet er skrevet slik Google forstår det.

Jeg setter opp Google Search Console og Google Bedriftsprofil, slik at du kan følge med på hvem som finner deg og hva de søker etter.

  • Teknisk SEO — meta-tags, canonical, robots.txt, sitemap
  • JSON-LD structured data for rich results i Google
  • Semantisk HTML-struktur (H1→H6, schema, landmarks)
  • Core Web Vitals optimalisering — LCP, CLS, FID
  • Lokal SEO og Google Bedriftsprofil

Verktøy og teknologi

JSON-LD Schema.org Search Console Sitemap Core Web Vitals Lighthouse Lokal SEO
03 Tekstforfatning +

De fleste nettsider er fulle av tekst som beskriver bedriften — men ikke overtaler kunden. Jeg skriver copy med ett mål: at den som leser skal ta kontakt.

Hvert ord er valgt med omhu. Overskrifter som stopper scrolling, brødtekst som bygger tillit, og en CTA som er umulig å overse.

  • Landingssider skrevet for konvertering, ikke for å imponere
  • Tjenestebeskrivelser som selger uten å virke påtrengende
  • Overskrifter som stopper thumbstopping på mobil
  • Konsekvent tone og stemme tilpasset din merkevare

04 Grafisk design +

En sterk merkevareidentitet gjør at du huskes. Jeg designer visuell identitet som fungerer konsistent på tvers av alle flater — fra nettsted til visittkort til Instagram.

Det starter gjerne med logo og fargepalett, og bygges ut til et komplett designsystem som du og teamet ditt kan bruke videre.

  • Logo — wordmark, symbol og kombinasjonsversjon
  • Fargepalett og typografisystem
  • Visittkort og trykkmateriell
  • Maler for sosiale medier
  • Brandbook / designguide

05 Programvare & AI-agenter +

Jeg bygger ikke bare nettsider — jeg utvikler programvare og AI-agenter som løser konkrete oppgaver for bedriften din. Fra egne interne verktøy til AI-agenter som utfører arbeid automatisk, uten at noen må gjøre det manuelt.

En AI-agent er mer enn en chatbot som svarer på spørsmål — det er kode som leser data, tar beslutninger og utfører handlinger på egen hånd. Alt skreddersydd for akkurat dine arbeidsflyter, ikke en ferdig mal.

  • Skreddersydde AI-agenter for automatisering av oppgaver
  • Egenutviklede verktøy og interne systemer
  • Integrasjon med KI-modeller (som Claude og GPT) i egne løsninger
  • Solid, testet kode — ikke løse no-code-snarveier

Verktøy og teknologi

AI-agenter Python Node.js Claude API OpenAI API Automatisering
06 API-integrasjoner +

Mange bedrifter mister tid på manuelt arbeid som egentlig kan automatiseres — en bestilling som må legges inn i kalenderen for hånd, en lead som må sendes til CRM-et, eller en ordre som må registreres i regnskapssystemet. Jeg kobler systemene dine sammen via API-er, slik at data flyter automatisk mellom dem.

API-nøkler og hemmeligheter håndteres sikkert bak kulissene — aldri eksponert i frontend-kode eller offentlige repoer.

  • Automatisering av manuelle arbeidsflyter mellom systemer
  • Kobler nettsiden til tredjepartstjenester — betaling, CRM, e-post, kalender
  • Webhooks som trigger handlinger automatisk
  • Sikker håndtering av API-nøkler og autentisering

Verktøy og teknologi

REST API Webhooks API-nøkler Autentisering Automatisering
07 Databaser (Supabase) +

En statisk nettside er ikke nok når du trenger ekte funksjonalitet — innlogging, bestillinger, medlemskap eller et adminpanel du kan redigere innhold i selv. Jeg bygger dette på Supabase, en Postgres-database med innebygd autentisering og sanntidsdata.

Det betyr at nettsiden din kan lagre og hente ekte data — ikke bare vise statisk innhold — samtidig som den fortsatt er rask og sikker.

  • "Logg inn"-funksjonalitet og brukerkontoer
  • Bestillings- og reservasjonssystemer koblet til database
  • Adminpanel hvor du redigerer innhold selv, uten kode
  • Row Level Security — riktig person ser riktig data

Verktøy og teknologi

Supabase PostgreSQL Row Level Security Autentisering Sanntidsdata Adminpanel
